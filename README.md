# Machine Learning and Deep Learning Practice

This repository contains my hands-on learning journey in Machine Learning (ML) and Deep Learning (DL) using Python and Google Colab. It includes experiments with regression, gradient descent, model evaluation, image processing, and neural networks.

## Topics Covered

- **Python Libraries:** NumPy, Pandas, Matplotlib
- **Machine Learning:** Linear Regression, Gradient Descent, Model Evaluation, Overfitting
- **Data Preprocessing:** Feature selection, one-hot encoding, and feature scaling
- **Deep Learning:** Neural Networks, Backpropagation, and Gradient Descent Optimization
- **Computer Vision:** Image processing, convolution, max pooling, and CNNs
- **Frameworks:** Scikit-learn, TensorFlow/Keras, and PyTorch

## Projects and Experiments

### 1. Medical Insurance Cost Prediction
- Dataset: Medical Cost Personal Dataset (1,338 records)
- Algorithm: Linear Regression
- Features: Age, BMI, smoking status, number of children, sex, and region
- Evaluation: R² score and Mean Absolute Error (MAE)
- Recorded test R² score: 0.784

### 2. Handwritten Digit Recognition
- Dataset: MNIST
- Framework: PyTorch
- Model: Convolutional Neural Network (CNN)
- Task: Classifying handwritten digits from 0 to 9
- Recorded test accuracy: 98.68% after three epochs

### 3. Smart Irrigation Predictor
- Framework: TensorFlow/Keras
- Model: A simple feed-forward neural network
- Features: Soil moisture, temperature, and sunlight hours
- Task: Predicting whether a crop field needs watering
- Dataset: A small synthetic dataset created for experimentation

### 4. Regression and Overfitting Experiments
- Implemented gradient descent from scratch.
- Explored how learning rates affect training.
- Compared models with different polynomial degrees to understand underfitting and overfitting.

### 5. Handwritten Letter Recognition
- Dataset explored: EMNIST Letters
- Task: Understanding image data preparation for handwritten letter classification.
- Status: Dataset setup and processing are still in progress.
